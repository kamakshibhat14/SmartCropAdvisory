# 🌱 AgroWise – Smart Crop Advisory System

AgroWise is a responsive, single-page web application that provides **data-driven crop recommendations** to farmers based on **soil type, rainfall, temperature, and region**.  
The project is developed as part of the **Advanced Web Technologies (AWT)** curriculum using **AngularJS and Bootstrap**.

---

## 🚜 Project Overview

Agriculture plays a vital role in the economy, and selecting the right crop based on environmental conditions is crucial.  
AgroWise helps farmers make informed decisions by analyzing field conditions and suggesting suitable crops through a user-friendly web interface.

---

## ✨ Features

- 👨‍🌾 Farmer Registration & Login (using browser localStorage)
- 🌾 Smart crop recommendation based on:
  - Soil type
  - Rainfall level
  - Temperature
  - Region
- 📊 Seasonal crop dashboard with visual charts (Chart.js)
- 💬 Contact & feedback form
- 🎨 Fully responsive and modern UI using Bootstrap
- ⚡ Single Page Application (SPA) using AngularJS routing
